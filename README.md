
# Pelora — Skincare E-commerce Website

A responsive skincare storefront concept built with React, Vite, and Tailwind CSS. Pelora features a soft, elegant design focused on skincare products and a smooth browsing experience across desktop, tablet, and mobile devices.

## 🌐 Live Demo

**[View Pelora Live](https://nasim-ho.github.io/Pelora/)**

## ✨ Features

- Responsive layout for desktop, tablet, and mobile
- Product carousel with Swiper navigation and autoplay
- Interactive category cards with hover effects
- Promotional discount banner
- Customer reviews carousel with fade transitions
- Scroll-triggered text reveal animations
- Sticky navigation header with a mobile menu
- Back-to-top button
- App download section and responsive footer

## 🛠️ Built With

- React
- Vite
- Tailwind CSS
- Swiper

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/nasim-ho/Pelora.git
```

Navigate to the project folder:

```bash
cd Pelora
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

To create a production build:

```bash
npm run build
```

## 📌 About This Project

Pelora is a front-end portfolio project created to practice responsive UI development, reusable React components, Tailwind CSS styling, and interactive animations.
